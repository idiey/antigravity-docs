# Antigravity Artifacts

This folder stores artifacts generated by Antigravity during your work sessions.

## Structure

| Folder | Purpose |
|--------|---------|
| [implementation-plans/](implementation-plans/) | Implementation plans before coding |
| [walkthroughs/](walkthroughs/) | Completed work documentation |
| [todo/](todo/) | Suggested todo items |

## Usage

Antigravity automatically creates artifacts in these folders during:

- **Planning sessions** → `implementation-plans/`
- **Completed tasks** → `walkthroughs/`
- **Task suggestions** → `todo/`

## Naming Convention

Files include date and description: `YYYY-MM-DD-[description].md`

Examples:

- `2026-01-10-auth-implementation.md`
- `2026-01-10-api-refactor-walkthrough.md`

## Integration

These artifacts can be referenced in:

- Daily logs for achievements
- Sprint planning for task tracking
- Checkpoints for context
