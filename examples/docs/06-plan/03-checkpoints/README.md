# Checkpoints

This folder contains work resumption checkpoints.

## Files

| File | Description |
|------|-------------|
| [TEMPLATE.md](TEMPLATE.md) | Template for new checkpoints |

## Usage

Run `/plan-checkpoint` to:

- **Save** - Create a checkpoint of current work state
- **Load** - Resume from a saved checkpoint
- **List** - View all available checkpoints

## Naming Convention

Use descriptive names: `[feature-name].md`

Examples:

- `auth-feature.md`
- `bug-fix-123.md`
- `refactor-api.md`

## Best Practices

1. Save checkpoint before taking a break
2. Include enough context to resume quickly
3. Update or delete checkpoints when work is complete
