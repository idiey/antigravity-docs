# Sprints

This folder contains sprint planning and retrospective documents.

## Files

| File | Description |
|------|-------------|
| [TEMPLATE.md](TEMPLATE.md) | Template for new sprints |

## Usage

Run `/plan-sprint` to:

- Create a new sprint
- View current sprint status
- Update task progress
- Close sprint with retrospective

## Naming Convention

Files are named by sprint number: `sprint-XX.md`

Example: `sprint-01.md`, `sprint-02.md`
