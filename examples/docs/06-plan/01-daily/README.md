# Daily Logs

This folder contains daily achievement and progress logs.

## Files

| File | Description |
|------|-------------|
| [TEMPLATE.md](TEMPLATE.md) | Template for new daily entries |

## Usage

Run `/plan-daily` to:

- Create today's entry from template
- View yesterday's unfinished tasks
- Update achievements throughout the day

## Naming Convention

Files are named by date: `YYYY-MM-DD.md`

Example: `2026-01-10.md`
